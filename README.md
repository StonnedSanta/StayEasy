# StayEase

StayEasy is a RESTful backend application for hotel booking management built with Spring Boot. It provides secure user authentication, role-based authorization, hotel management, and booking workflows.

## Features

- JWT-based authentication
- BCrypt password encryption
- Role-based access control (Customer, Hotel Manager, Admin)
- Hotel management
- Room booking and availability management
- Booking validation and business rule enforcement
- Centralized exception handling

## Tech Stack

- Java 25
- Spring Boot
- Spring Security
- Spring Data JPA (Hibernate)
- JWT
- BCrypt
- MySQL
- Gradle
- Lombok
- JUnit
- Mockito
- Git & GitHub
